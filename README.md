# Serial Port Terminal（串口终端）

VS Code 串口终端插件：在侧边栏管理串口设备，一键连接，在真正的终端面板里与设备交互。

## 功能

- **设备管理视图**：活动栏入口，列出系统串口设备，展示厂商信息、悬停详情与连接状态
- **热插拔侦测**：周期性扫描（间隔可配置、可关闭），设备插入/拔除自动增删列表
- **连接状态显示**：未连接 / 连接中 / 已连接，带视觉反馈，打开失败自动回滚并提示原因
- **内置终端**（VS Code Pseudoterminal）：接收数据原样显示，在终端内键入、回车发送
- **断开保留日志**：断开后终端面板保留，可继续回看本次会话日志
- **快捷配置管理**：为每台设备保存多份命名连接配置（预设参数组合），支持添加、重命名、删除，悬停查看完整参数；连接时可选用保存的配置或预设组合（不保存）；连接中高亮当前使用的配置，上次使用的配置自动置顶
- **预设管理界面**：视图标题栏齿轮按钮打开预设列表，四步向导新增/编辑，支持删除，无需手改 JSON
- 界面本地化：英文 / 简体中文

## 使用方法

1. 点击活动栏的串口管理器图标
2. 点击设备上的连接按钮，在弹出的参数选择器中选择保存的配置或预设组合（不会保存）
3. 自动弹出终端面板 —— 设备发来的数据实时显示，键入内容后回车发送
4. 在设备条目上断开连接，或直接关闭终端面板

## 配置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `serialPortTerminal.hotPlugEnabled` | `true` | 是否启用热插拔侦测 |
| `serialPortTerminal.pollingInterval` | `2` | 轮询间隔（秒），范围 1–15 |
| `serialPortTerminal.serialConfigPresets` | 8 个常用组合 | 连接/添加配置时可选的预设参数组合（建议经视图标题栏的「管理预设组合」界面编辑） |
